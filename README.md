# contracts

Solidity smart contracts built with Hardhat 3, OpenZeppelin, and ERC1967 upgradeable proxies.

## Stack

- Hardhat 3 + ethers.js + chai
- OpenZeppelin Contracts (upgradeable)
- ERC1967 proxy pattern (UUPS)

## Setup

```shell
npm install
```

## Compile

```shell
npx hardhat compile
```

## Test

```shell
npx hardhat test
```
